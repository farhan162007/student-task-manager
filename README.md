# Student Task Management App

A simple web-based **Student Task tarcker** developed as a collaborative Git and GitHub project. The application allows users to create, view, complete, delete, and search tasks while demonstrating a practical software-development workflow using Git and GitHub.

## Project Description

The Student Task Manager was developed as a pair-based collaborative project to demonstrate Git and GitHub concepts in a real development workflow.

The project covers local Git repository management, feature branches, commits, GitHub Issues, Pull Requests, code reviews, merging, merge-conflict resolution, Git recovery commands, version tagging, and GitHub Releases. These activities follow the workflow required by the collaborative assignment.

## Git Workflow

The project followed a collaborative feature-branch workflow:

```text
Create Project
      ↓
Initialize Git
      ↓
Create Commits
      ↓
Create GitHub Repository
      ↓
Create Feature Branches
      ↓
Develop Features
      ↓
Push Branches
      ↓
Create Issues
      ↓
Create Pull Requests
      ↓
Code Review
      ↓
Merge
      ↓
Resolve Merge Conflict
      ↓
Git Recovery
      ↓
Tag v1.0.0
      ↓
GitHub Release
```

Feature development was performed on separate branches rather than directly on `main`.

## Branches

## How to Run

No server or additional installation is required.

1. Clone the repository:

```bash
git clone <repository-url>
```

2. Open the project folder:

```bash
cd student-task-manager
```

3. Open `index.html` in a web browser.

The application can also be opened directly by double-clicking `index.html`.
